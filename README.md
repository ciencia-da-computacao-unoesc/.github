# 🎓 Ciência da Computação - Unoesc Maravilha

Bem-vindo(a) à organização do GitHub dos estudantes de **Ciência da Computação** da **Universidade do Oeste de Santa Catarina (Unoesc)** - *Campus Maravilha*.

Esta organização foi criada para centralizar, compartilhar e preservar os códigos, projetos, trabalhos acadêmicos e materiais de estudo desenvolvidos ao longo das disciplinas do curso.

---

## 📂 Padrão e Estrutura de Repositórios

Para manter o nosso GitHub estruturado, encorajamos que os repositórios sejam criados seguindo as fases (semestres) do curso ou separando por grandes projetos de extensão/pesquisa.

Sugestão de categorias de repositórios:
- 📁 `Fase-01` a `Fase-08`: Materiais, listas de exercícios e trabalhos das disciplinas de cada semestre.
- 📁 `TCC`: Repositórios destinados a protótipos e sistemas de Trabalhos de Conclusão de Curso.
- 📁 `Maratonas`: Códigos de treinamento, maratonas de programação e Hackathons.
- 📁 `Projetos-Integradores`: Softwares desenvolvidos em conjunto pelas turmas.

> **Dica de Nomenclatura para Repositórios:** `[Semestre/Fase]-[NomeDaDisciplina]-[Ano]`  
> *Exemplo:* `Fase03-EstruturaDeDados-2026` ou `Fase04-BancoDeDados-2026`

## 📝 Convenções de Commits

Para manter o histórico do repositório limpo e compreensível, adotamos a seguinte padronização para as mensagens de commit:

| Tipo | Quando Usar | Exemplo |
| :--- | :--- | :--- |
| **feat** | Nova Funcionalidade | `[NOME_APP] feat: Comentário` |
| **fix** | Correção de BUG | `[NOME_APP] fix: Comentário` |
| **update** | Atualização de funcionalidade | `[NOME_APP] update: Comentário` |
| **refactor** | Refatoração sem mudar comportamento | `[NOME_APP] refactor: Comentário` |
| **style** | Mudança de estilização | `[NOME_APP] style: Comentário` |
| **docs** | Documentação | `[NOME_APP] docs: Comentário` |
| **perf** | Melhorias de performance | `[NOME_APP] perf: Comentário` |
| **test** | Testes | `[NOME_APP] test: Comentário` |
| **chore** | Tarefa de Manutenção | `[NOME_APP] chore: Atualiza requirements` |
| **db** | Mudanças no Banco de Dados | `[NOME_APP] db: Comentário` |

## 🤝 Como Contribuir

Todos os estudantes do curso de Ciência da Computação da Unoesc Maravilha são muito bem-vindos(as) a participar e colaborar!

1. Solicite acesso à organização falando com os responsáveis ou com os administradores atuais da organização.
2. Navegue até o repositório da disciplina desejada.
3. Crie uma pasta para o seu trabalho/projeto (ex: `/Trabalho-Final-NomeDoAluno`).
4. Faça seus *commits* com descrições claras sobre o que o código faz.
5. Siga as boas práticas de programação e mantenha o código limpo.

⚠️ **Importante:**
- Evite subir arquivos compilados desnecessários (configure o seu `.gitignore`).
- **NUNCA** compartilhe chaves de API, senhas ou dados sensíveis nos repositórios.
- Respeite o código dos colegas e os prazos de entregas definidos pelos professores.
